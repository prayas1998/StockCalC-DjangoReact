# Equity calculator assumptions

The calculator estimates order charges for one equity instrument and exchange per request. For intraday estimates, submit each instrument and trading day separately. Contract notes can aggregate regulatory fees across instruments and may differ by rupee or paise rounding.

## Orders and depository debits

A row represents one order on each nonzero side unless fills share a `buyOrderId` or `sellOrderId`. These IDs refer to the actual buy and sell sides. In a short request, `buyPrice` remains the entry (sell) price and `sellPrice` remains the cover (buy) price. Brokerage is calculated once per order and appears on its first reported fill. Groww applies its ₹20 cap and lower-of-₹5-or-2.5% minimum to each order. Dhan delivery brokerage is zero and Dhan intraday brokerage is 0.03% capped at ₹20 per order. [Groww equity brokerage](https://groww.in/help/stocks%2C-f%26o-%26-ipo/searchable/how-much-is-the-brokerage), [Dhan pricing](https://dhan.co/pricing/)

Groww delivery charges per sell order. The default `growwDpRate: "standard"` gives ₹4.13 for a debit below ₹100 and ₹23.60 at ₹100 or more, including GST. With `growwDpRate: "female"`, the respective charges are ₹3.84 and ₹23.31. Dhan charges ₹14.75 per debit instruction for the instrument. Use the same `debitInstructionId` for fills grouped into one Dhan debit, including when several sell orders share the instruction. Without it, Dhan treats each sell order as one instruction. The calculator form treats each row as a separate order and Dhan debit. Tools assume one order on each side and the standard Groww depository rate. [Groww DP tariff](https://groww.in/help/stocks/searchable/when-are-dp-charges-levied), [Groww sell-order examples](https://groww.in/help/stocks/searchable/are-dp-charges-per-stock-or-per-order), [Dhan debit tariff](https://dhan.co/support/general/pricing/dp-charges-will-be-levied-for-every-delivery-sell-order-per-scrip-per-day-for-any-given-quantity/)

## Statutory fees and tariff date

- Intraday STT on NSE and BSE uses the smaller of buy and sell quantity multiplied by the all-execution VWAP rounded to paise, then applies 0.025%. The intraday component is rounded to paise before the isolated estimate is rounded to the nearest rupee. Unmatched shares contribute to the VWAP. This is an intraday estimate, so any later delivery conversion, auction, or automatic square-off requires the actual settlement details. [Securities Transaction Tax Rules, Rule 3](https://www.sebi.gov.in/sebi_data/attachdocs/apr-2017/1492087548939.pdf), [NSE netted-settlement method](https://nsearchives.nseindia.com/content/circulars/cmtr5588.htm), [Groww STT guide](https://groww.in/blog/how-is-stt-levied)
- Without a `tradeDate`, the API and Tools use the NSE cash tariff effective 1 March 2026. Dhan reports ₹306.99 exchange fees and ₹0.01 IPFT per crore. For Groww, the calculator estimates the NSE combined rate of ₹307 per crore in `charges.exchangeAndIpft`, with the individual fields set to null. The pricing and support pages publish different exchange fees, and their currently listed IPFT makes the breakdown ambiguous. A current Groww contract note is needed to confirm the actual allocation and total. [NSE tariff revision](https://nsearchives.nseindia.com/content/circulars/FA73061.pdf), [Dhan pricing](https://dhan.co/pricing/), [Groww pricing](https://groww.in/pricing), [Groww intraday help](https://groww.in/help/stocks/sx-pricing/what-are-intraday-charges)
- A `tradeDate` before 1 March 2026 selects the previous modeled NSE rates of ₹297 exchange fees and ₹10 IPFT per crore. This selects the prior exchange tariff only. Journal P&L uses the tariff shared by the two recorded trading dates when both orders fall in the same period. For trades spanning the revision it uses the later tariff for the entire estimate. Records without both dates use the current tariff. Legacy delivery records marked Short have unavailable P&L and retain their stored fields. The current retail delivery estimator supports long positions. Historical brokerage, DP changes and older tariffs require dated contract notes. The BSE estimate uses the standard ₹375 per crore in both periods. Other scrip groups can have different rates. For example, at ₹20,000 turnover the standard fee is ₹0.75, while X-group fees are ₹20. [NSE October 2024 tariff](https://nsearchives.nseindia.com/content/circulars/FA64232.pdf), [NSE March 2026 revision](https://nsearchives.nseindia.com/content/circulars/FA73061.pdf), [Dhan pricing](https://dhan.co/pricing/), [Groww pricing](https://groww.in/pricing)

## P&L and breakeven

The existing `grossPnL` and `netPnL` fields represent matched shares using weighted buy and sell prices. The net calculation attributes side-specific charges by the matched fraction on the relevant side and common charges by turnover. GST follows the attributed taxable charges. `openQuantity`, `openSide`, and `openCashFlow` separately describe unmatched executions and attributed charges. An exit with no corresponding entry supplies cash flow but has no known basis here. `cashFlow` includes all executed legs and fees.

Breakeven uses one hypothetical closing order on the ₹0.01 price grid. For a partially closed position it preserves prior exits and closes the remaining shares (`remaining`). For a fully closed set of orders it estimates a common exit across all entries (`full`). The result is the first non-loss sell tick or the highest non-loss cover tick. The API reports `breakevenMode: "unavailable"` with `breakevenPrice: "0.00"` when it cannot quote a positive exit within the supported paise grid. The scrip's actual tick size and daily price bands require instrument-specific exchange data. [NSE tick-size schedule](https://nsearchives.nseindia.com/content/circulars/CMTR67133.pdf), [BSE equity master circular](https://www.bseindia.com/markets/MarketInfo/DownloadAttach.aspx?attachedId=cb125690-a0f8-452a-ba6b-86cab98004bc&id=20230630-19)

The regression suite uses synthetic API trades. Compare one dated, redacted contract note per broker and any separate depository ledger charges before using estimates as a reconciliation source.
